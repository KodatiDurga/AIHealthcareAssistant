Medical Report Comparison

Analyze saved reports and compare matching laboratory results from an earlier report with a newer report.

Select reports

Only matching laboratory test names with the same units are numerically compared. Different report types (for example, a blood test and a chest X-ray) are analyzed separately. This module does not interpret X-ray, MRI, or CT image pixels.

How this comparison works

1. Existing PDF is read using text extraction. Scanned PDFs use OCR if Tesseract is installed.
2. The service extracts a limited set of common laboratory markers.
3. Python compares matching markers and checks unit compatibility.
4. The output is a structured comparison, not a disease diagnosis.
